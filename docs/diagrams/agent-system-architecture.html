Domain boundary

领域事实与编排状态分离

ResearchRun、TaskOutcome、Evidence、Citation、Memory、Tool Approval 和 RunEvent 在数据库中形成可审计事实；LangGraph checkpoint 只保存恢复所需的内部状态。

Evidence path

证据先冻结，再进入 Agent

  • 检索先做 Workspace ACL、软删除和版本有效性过滤。
  • 来源正文回读后才能生成 Evidence Span 和 Citation。
  • Research Record 与 Long-term Memory 保持分离。

Operational edge

Worker 是长任务边界

API 不运行长时 Agent。Worker 领取租约、发送 heartbeat、执行恢复，并通过 fencing epoch 防止失效 Worker 继续提交事实。
